## 6. Comment lire le document

- **Surlignage jaune = à faire** : une consigne, un point à vérifier ou une valeur à compléter. Le rapport est terminé quand il n'y a plus de jaune.
- Les consignes commencent par le **nom de la personne responsable** (par exemple « MAMA ADAM (≈ 1 page) : … »).
- Ne modifiez pas le fichier Word directement : écrivez dans votre fichier `docs/rapport/<prenom>.md`. Maïmouna regénère le document à partir de toutes les contributions.
